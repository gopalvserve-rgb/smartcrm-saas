01🚀 First login

From zero to your first lead in under five minutes.

  1. Open your workspace URL.

    Visit https://crm.smartcrmsolution.com/t/<your-slug>/ — replace <your-slug> with the workspace name you signed up with (eg. vserve). Bookmark it.

  2. Log in with the admin email.

    Use the email + password you set during signup. If you forgot the password, click "Forgot password?" on the login screen.

  3. Set your company branding.

    Settings → Company. Upload your logo, set the company name, and pick a brand colour. These show on the login screen, the sidebar, the topbar, and the Android app icon area.

  4. Add your team.

    People → Users → Add user. Enter their email, set a role, optionally set a daily/monthly lead cap. They'll get an invite email.

  5. Customise statuses for your pipeline.

    Settings → Statuses. Add the stages you actually use (eg. New, Contacted, Qualified, Quote Sent, Won, Lost) and pick colours for each.

✅
Done with the basics? Next decide where leads come from — webhook (most flexible), Meta Lead Ads, Google Ads, CSV import, or all of them.

02👥 Users & roles

Add team members and pick what they can see and do.

  1. Add a user.

    People → Users → Add user. Fill name, email, phone, role.

  2. Pick the right role.
    adminFull access. Can manage settings, billing, integrations.
    managerCan see all leads, assign to anyone, but can't edit settings.
    agentSees only leads assigned to them.

    Custom roles? Settings → Roles lets you build your own combinations.

  3. Set lead caps (optional).

    Each user can have a Daily lead cap and Monthly lead cap. The auto-assigner respects these — agents who hit their cap stop receiving new leads until midnight / month-rollover.

  4. Activate or deactivate.

    To pause a user, toggle their Active flag off. Their leads stay visible to managers; they can no longer log in.

03🟢 Statuses

The funnel stages every lead moves through.

  1. Open Settings → Statuses.
  2. Add a status. Click Add status, give it a name (eg. Site Visit Booked), pick a colour, and set a sort order. Lower numbers appear higher in the list.
  3. Mark final statuses. Tick Is final for terminal stages like Won, Lost, Junk. Final statuses are excluded from "Open leads" counts and dashboard funnels.
  4. Default status for new leads. The system uses New by default. If you delete or rename it, set the new default in Settings → Statuses → Default for new leads.
💡
Status colours are used everywhere — kanban, dashboard pie charts, lead list pills, even the WhatsApp chat header. Pick semantic colours (green = good, red = lost, yellow = waiting).

04🔍 Sources & tags

Track where leads come from (Source) and add free-form labels (Tags).

  1. Add sources. Settings → Sources. Examples: Website, Meta Ads, Google Ads, Walk-in, Referral, Trade Show 2026.
  2. Sources are auto-created from webhooks. When a lead arrives via /hook/website with source=Foobar, a Source row called Foobar is created automatically the first time it's seen.
  3. Tags are free-form. Type any label on a lead — VIP, callback-tomorrow, quote-sent-v2. Comma-separated. Good for ad-hoc segmentation.

05➕ Custom fields

Track anything specific to your business — budget, requirement, property type, course interested in.

  1. Open Settings → Custom Fields.
  2. Click "Add field". Fill in:
    Keycampaign_name_new — internal identifier, lowercase, no spaces. This is what webhooks send.
    LabelCampaign Name — what users see on the lead form.
    TypeText / Number / Date / Dropdown / Multi-select
    Options(Dropdown only) one option per line
    Show in listTick to make it a column on the lead grid
    RequiredTick to enforce on the lead form
  3. Webhooks pick it up automatically. Once a custom field exists, /hook/website reads b[<key>] on the inbound payload and stores it on the lead. Pabbly / Make / Zapier mappings just need the key (eg. campaign_name_new) — not the label.
  4. Filter / report on it. Lead list → Filter dropdown shows your custom fields. Reports → Group by includes them too.
⚠️
Avoid renaming a key after data is saved — old rows still reference the old key. If you must rename, contact support so we can re-key your existing data.

06📦 Products

A catalogue of what you sell. Used by Quotations and on the lead form.

  1. Settings → Products → Add product. Name, description, price, active flag.
  2. Pick a product on a lead. Lead form → Product dropdown searches your catalogue.
  3. Use in Quotations. Quotations module pulls from this list — the product picker shows price, your team can override per-quote.

07⚖️ Auto-assign rules

When a lead arrives, send it to the right person automatically.

  1. Settings → Auto-assign Rules → Add rule.
  2. Define the match.
    FieldSource / City / Product / Phone area / Custom field (cf:<key>)
    Operatorequals / contains / starts with / ends with
    ValueThe literal value to match
    Assigned toOne or more users (round-robin among them)
    PriorityLower = higher priority. First matching rule wins.
  3. Round-robin within the rule. When multiple users are assigned to one rule, the system picks the user with the fewest open leads today — keeping load even.
  4. Lead cap fallback. If the chosen user has hit their daily/monthly cap, the rule skips to the next user.
  5. Disabling a rule. Untick Active on the rule row.
💡
For more sophisticated routing — quotas, percentages, conditional logic — use Campaigns instead. Auto-assign rules are the simple "if-this-then-that" path.

08🎯 Campaigns

Group leads by ad campaign or source, route them across agents using one of five modes.

  1. Settings → Campaigns → Add campaign.
  2. Pick a distribution mode.
    On DemandLeads stay unassigned until an agent calls Pull. Pulls happen in batches you size below.
    EqualNew leads spread evenly across all agents over time.
    Round RobinStrict cursor — A, then B, then C, then back to A. Order is deterministic across server restarts.
    PercentageEach agent gets a fixed % of new leads. Must add up to 100%.
    ConditionalRoutes by Source / Status / Custom-field rules you define inside the campaign.
  3. Choose lead-filter rules. Inside the campaign modal, decide which incoming leads belong to it — eg. source = Meta Ads AND cf:campaign_name_new contains "Nh-24". Leads matching join the campaign automatically.
  4. Add agents. Pick the users in this campaign. For Percentage mode, set each user's % directly.
  5. Removed-user action. When an agent leaves the campaign, decide what happens to their leads: reassign within campaign, unassign, or leave with the agent.
  6. Pause / resume. Toggle the Active switch. Paused campaigns don't accept new leads but keep existing assignments.

09⏱️ TAT (response SLA)

Alert when a lead sits untouched too long.

  1. Settings → TAT.
  2. Set the SLA. "First response within X minutes/hours of lead creation". Eg. 30 minutes for hot Meta Lead Ads.
  3. Set escalation. If the agent doesn't respond in time, optionally re-assign to a manager OR push a notification to the team.
  4. Watch the TAT report. Reports → TAT Report shows breaches by user, by stage, and by source. Excel download available.

10🚚 Project stages

For service / project businesses — track delivery progress separately from the sales pipeline.

  1. Settings → Project Stages → Add stage. Examples: Site Survey, Design, Procurement, Installation, Handover.
  2. Set expected days. The dashboard flags any project sitting in a stage longer than expected.
  3. Assign a default role per stage. Eg. Procurement stage auto-assigns to a Procurement Manager.
  4. Move leads through stages. Lead detail page → Project Stage dropdown.

11👥 Duplicate handling

What happens when the same phone or email comes in twice.

  1. Settings → Duplicates.
  2. Pick a policy.
    allowCreate both, but flag the new one as "duplicate of #X" (default).
    rejectRefuse the second submission entirely.
    assign_same_userCreate the lead, but assign it to whoever owns the original.
    skip_assignmentCreate unassigned (manager will triage).
  3. Set the window. "Treat as duplicate if same phone arrives within X hours" — default 24h.
  4. See duplicates. Lead list → Filter → "⚠️ Duplicates only" or use the bulk Dedupe button.

12🔌 Website API webhook

The most flexible way to push leads in — your website, your forms, any tool that can POST JSON.

  1. Get your API key. Settings → Website API → click Regenerate if you don't see one yet. Copy the key.
  2. POST a lead. Send a JSON body to:
    https://crm.smartcrmsolution.com/t/<your-slug>/hook/website
    With either header x-api-key: <your-key> or Authorization: Bearer <your-key>.
  3. Required fields.
    nameRequired Lead's name
    phoneRequired Mobile number (with country code)
    emailOptional
    sourceRecommended Eg. Website, Meta Ads
    productOptional
    notesOptional Free text
    tagsOptional Comma-separated string or JSON array
    city, state, country, pincode, company, addressOptional
    campaign_name / campaign_idOptional Aliases accepted: campaign_name_new, campaignName, campaign_title etc.
    Any custom field keyOptional The system reads every active custom field and writes matches into extra_json. Send the value at b[<key>], b[cf_<key>], or b.extra[<key>].
  4. Test it. 
    curl -X POST https://crm.smartcrmsolution.com/t/<slug>/hook/website \
  -H "Content-Type: application/json" \
  -H "x-api-key: <your-key>" \
  -d '{
    "name": "Test Lead",
    "phone": "9876543210",
    "email": "test@example.com",
    "source": "Website",
    "product": "Demo",
    "notes": "Came from contact form"
  }'
    You should get {"ok":true,"id":123}.
  5. Watch live activity. Settings → Website API → Recent inbound shows the last 50 webhook hits with raw body and any errors. Use this to debug bad mappings.
⚠️
Phones with fewer than 10 digits are auto-flagged as Junk instead of being rejected, so they're visible without polluting the active pipeline.

13🔗 Pabbly Connect

Bridge Meta Lead Ads, Instagram, Google Forms, JustDial, IndiaMart and 800+ other sources into SmartCRM.

  1. Set up the trigger. Eg. Facebook Lead Ads → choose your page → choose your form.
  2. Add an "Action — API by Pabbly" step.
  3. Method: POST.
    URL:
    https://crm.smartcrmsolution.com/t/<your-slug>/hook/website
  4. Headers.
    x-api-keyYour Website API key (Settings → Website API)
    Content-Typeapplication/json
  5. Body type: Raw → JSON. Map the fields:
    nameDrag the lead's name field
    phoneDrag the phone field
    emailDrag the email field
    source"Meta" (or whatever channel)
    campaign_nameDrag the campaign-name field value chip only — don't drag the labelled chip with "Res1 Campaign Name :" prefix.
    campaign_idDrag the campaign-ID field
    Custom fieldsUse the exact key from Settings → Custom Fields, eg. campaign_name_new.
  6. Test send. Pabbly's Send Test Request button. Confirm you get {"ok":true,"id":...}. The lead should appear in SmartCRM within seconds.
  7. Save and turn on the workflow.
💡
If a custom field shows as empty in the lead, check Settings → Website API → Recent inbound — the raw body tells you exactly what Pabbly sent. Most problems are field name typos (campaign_Name vs campaign_name).

14🧩 Make.com

Same idea as Pabbly — Make.com (formerly Integromat) sends leads via the Website API.

  1. Build a scenario. Trigger from Facebook / Typeform / a Sheet / wherever.
  2. Add an "HTTP — Make a request" module.
  3. Method: POST. URL: the same /t/<slug>/hook/website.
  4. Headers: x-api-key: <your-key>, Content-Type: application/json.
  5. Body type: Raw → JSON (application/json). Build the JSON payload using the field mapper.
  6. Run once with a sample input to verify, then turn the scenario on.
💡
SmartCRM has a dedicated Make.com card on Settings → Integrations — it shows a sample payload and a Test-send button so you can verify the connection without leaving the CRM.

15⚡ Zapier & n8n

Same recipe again — POST JSON to the Website API webhook.

  1. Zapier: Add a "Webhooks by Zapier — POST" action. URL = /t/<slug>/hook/website. Add headers + JSON body. Map the fields. Done.
  2. n8n: Use the "HTTP Request" node. Method POST, URL same, Authentication = Header Auth (x-api-key), Body JSON, map fields.
  3. For high volume: Use Pabbly's per-execution pricing for predictable cost. Make/n8n charge by operations, Zapier by tasks.

16📘 Meta (Facebook) Lead Ads

Two ways to wire it up — direct (Facebook → SmartCRM) or via Pabbly. Direct is faster but has less flexibility.

Option A — Direct via Facebook OAuth (recommended for one or two pages)

  1. Settings → Facebook → Connect Facebook account. A Facebook OAuth popup opens.
  2. Approve permissions. SmartCRM needs leads_retrieval + pages_manage_metadata.
  3. Pick the Page(s). Tick the pages whose leads you want to receive.
  4. Pick the Form(s). Tick the lead-gen forms inside each page.
  5. Webhook auto-subscribes. SmartCRM registers our central webhook with Meta automatically — no need to copy URLs into Meta's Developer console.
  6. Test it. Use Meta's "Lead Ads Testing" tool inside Facebook Business Suite to fire a test lead. It should appear in SmartCRM within a few seconds.

Option B — Pabbly bridge (when direct doesn't work, eg. agency-managed pages)

Use the Pabbly Connect recipe above with Facebook Lead Ads as trigger.

17🟡 Google Ads ValueTrack

Capture {campaignid}, {keyword}, {gclid} and friends straight off the landing page.

  1. On your landing page, add ValueTrack params to the form action URL or read them off window.location.search: 
    ?campaign={campaignid}&campaign_name={campaignname}&network={network}&keyword={keyword}&gclid={gclid}&adgroupid={adgroupid}&matchtype={matchtype}&device={device}
  2. Submit them with the lead. Include the params in your POST body to /hook/website (alongside name/phone/email).
  3. What gets stored. SmartCRM normalises Google Ads params into both first-class columns AND meta_json — so any reports already built on either keep working:
    gclidFirst-class column. Use it to upload offline conversions back to Google Ads.
    gad_campaignidFirst-class column.
    utm_*UTM source/medium/campaign/term/content all populated.
    SourceAuto-set to Google Ads when gclid or campaign is present (unless you pass source explicitly).
    TagsCampaign name + network are auto-added as tags.
  4. Reports. Reports → Group by → UTM campaign shows leads + conversions per Google Ads campaign.

18📥 CSV import (LeadSquared, Zoho, HubSpot, Salesforce)

Migrating from another CRM? The Import wizard knows the column names.

  1. Export from your old CRM. CSV format. UTF-8 encoded. Make sure phone numbers aren't in scientific notation (Excel does this — open in Google Sheets or use plain Numbers/text format).
  2. Settings → Integrations → Import → Upload CSV.
  3. Pick your source platform. LeadSquared / Zoho / HubSpot / Salesforce / Generic. The wizard auto-detects column names for the first four.
  4. Map any unmapped columns. The wizard shows a side-by-side: their column → SmartCRM field. Custom fields are pre-listed so you can map directly into them.
  5. Preview the first 5 rows. Make sure phones look right, statuses match (the wizard maps them to your existing statuses or asks you to create new ones), no NaN or shifted columns.
  6. Import. The job runs in the background. You'll see a counter as rows land. Duplicates respect your duplicate policy.

19📅 Calendly

Auto-create a lead (or update an existing one) when someone books a meeting.

  1. Get your per-user webhook token. Settings → Users → click your name → copy the Calendly webhook token.
  2. In Calendly, set up a webhook. Account → Integrations → Webhooks → Create. URL:
    https://crm.smartcrmsolution.com/hook/calendly/<your-token>
    Subscribe to invitee.created.
  3. Match logic. When a Calendly booking arrives, SmartCRM matches by phone and email. If a lead exists, it updates next_followup_at to the booking time. If not, it creates a new lead assigned to you.

20💬 WhatsApp Cloud API

Send + receive WhatsApp messages from inside SmartCRM. Two paths: Embedded Sign-In (recommended) or manual setup.

Path A — Embedded Sign-In (5 minutes, no Meta dev console)

  1. Settings → WhatsApp → "Connect WhatsApp Business".
  2. Sign in with Facebook. Use the FB account that owns your business.
  3. Create or pick a WhatsApp Business Account (WABA). Pick one if you have it; create if not.
  4. Pick a phone number. Either a new number Meta provisions for you, or an existing landline/business mobile (you'll get an OTP to verify).
  5. SmartCRM auto-registers the webhook with Meta + persists the access token. No copying URLs into Meta's Dev Console.
  6. Send a test message. WhatsApp tab → pick a contact → type → Send. You should see the message arrive on the destination phone within seconds.

Path B — Manual setup (only if Embedded Sign-In doesn't work for you)

  1. In Meta Developer Console, create a WhatsApp Business app. Get Phone Number ID, WhatsApp Business Account ID, and a permanent Access Token.
  2. Set the webhook URL to https://crm.smartcrmsolution.com/t/<your-slug>/hook/whatsapp_webhook. Subscribe to messages.
  3. Set the verify token to anything you choose, then paste the same value into SmartCRM Settings → WhatsApp → Verify token.
  4. Paste the access token + phone number ID into SmartCRM Settings → WhatsApp.
  5. Save and verify. Send yourself a test message.

21🤝 WhatsApp Coexistence mode

Keep using the WhatsApp Business app on your phone and the SmartCRM web inbox on the same number — at the same time.

  1. During Embedded Sign-In, tick the Coexistence mode option in the SmartCRM dialog before authorising.
  2. Approve in Facebook. Meta shows a different consent screen — read the differences (you can no longer block users from the app, group chats are read-only via API, etc.).
  3. Now both surfaces are live. Reply from the phone? It shows up in SmartCRM's chat thread. Reply from SmartCRM? It pops up on the phone. Push notifications continue working on the phone.
⚠️
Coexistence has trade-offs vs full Cloud API: no template messages outside 24-hour customer service window, no broadcast lists, group messaging is API-read-only. Switch off Coexistence later if your needs grow.

22📱 Multiple WhatsApp numbers

Connect more than one WhatsApp number — eg. one for sales, one for support.

  1. Settings → WhatsApp → Connected numbers.
  2. Click "Connect another number". Same Embedded Sign-In flow as the first number; pick a different phone.
  3. Pick the default sender per agent (optional). Settings → Users → click an agent → Default WhatsApp sender. Otherwise the system uses whichever number was the inbound number for that thread.
  4. Send-from picker. When composing a new outbound (no existing thread), the chat compose box now shows a dropdown — pick which connected number to send from.
  5. Per-number filter on the inbox. The chat thread list has a per-phone filter at the top — handy when you want to see only support-line conversations.

23📨 WhatsApp templates

Pre-approved messages you can send outside the 24-hour customer service window.

  1. Settings → WhatsApp → Templates → Create template.
  2. Pick category: Marketing / Utility / Authentication. Categories have different cost and approval rules.
  3. Pick language. One language per template.
  4. Compose. Header (optional), body, footer (optional), buttons (optional). Use {{1}}, {{2}} etc. for variables — these get filled in at send time.
  5. Submit. Meta reviews approve in 0–24h. You'll see status update from PENDING → APPROVED on the Templates tab.
  6. Use it. Either from the chat compose box ("Send template") or via the WhatsApp Campaign builder (bulk-send to a lead segment).

24🤖 AI WhatsApp Bot

Auto-reply to inbound WhatsApp messages with a Gemini-powered assistant trained on your business knowledge.

  1. Sidebar → AI Bot → Bot Settings.
  2. Enable the bot. Tick Enabled.
  3. Pick a goal template. Sales / Support / Site visit / Appointment booking / Custom. Each pre-fills a system prompt tailored for that goal.
  4. Pick reply mode.
    alwaysAuto-send replies. Best for first-touch + FAQs.
    manualGenerate a draft and queue it for your agent to review/send. Best for complex sales.
    after-hoursOnly auto-reply outside business hours.
  5. Pick language. The bot replies in the language you pick — English, Hindi, Hinglish, Marathi, Tamil, Telugu, Bengali, Kannada, etc. The model auto-detects too if you leave it on Auto.
  6. Set "Resume after idle". If a human agent has replied recently, the bot stays quiet to avoid duelling responses. Default 2 minutes — bump up if your agents take longer to read incoming messages.
  7. (Optional) Off-keywords. Eg. human, agent, talk to, stop bot. The bot pauses on threads where these appear.
  8. Save. The bot is now live on every inbound that doesn't match a Message Bot or Template Bot trigger.
💡
Watch live activity at AI Bot → Bot Activity. Every inbound + reply (or suppression reason) is logged.

25📚 AI Knowledge Base

Train the AI Bot on YOUR business — pricing, hours, services, FAQs, anything.

  1. AI Bot → Knowledge Base → Add document.
  2. Three ways to add knowledge:
    Paste textBest for FAQs, short policies, lists. Up to 200,000 chars per document.
    Crawl a URLPaste a public URL — the system fetches and extracts text. Good for product pages, terms, return policies.
    Upload a file BetaPDF / DOCX / TXT. Text gets extracted and stored.
  3. Toggle individual documents on/off. A doc can be in the KB but inactive — useful for seasonal info.
  4. Watch the per-call cost. AI Bot → Usage & Cost. The KB is appended to every prompt, so big KBs = high cost. Recommended KB max chars per call = 8,000 (about 2,000 tokens). Drops cost by up to 80% with minimal answer-quality loss.
⚠️
Don't dump your entire website into the KB. The bot answers better with curated, well-structured content. Quality > quantity.

26✨ CRM Copilot (Ask CRM)

Type plain-English questions about your CRM data — get answers + charts.

  1. Click the floating ✨ button (bottom-right of any page). Drag it anywhere; it remembers position.
  2. Ask anything. Examples:
    • "How many leads from Meta Ads last month?"
    • "Show me the pipeline funnel for vserve."
    • "Who are my top 5 agents by conversion this quarter?"
    • "Why is TAT slipping?"
    • "Show me leads stuck in Qualified for more than 7 days."
  3. Tools the Copilot has access to. Pipeline funnel, lead counts/searches, conversion rates, TAT analysis, employee stats, recordings, quotations — 33 tools total.
  4. Daily limit. Each user has a per-day Copilot quota (configurable per package). When you hit it, the next call shows a "limit reached" notice.

28🔔 Mobile push notifications

Banner + sound + vibration on the phone even when the app is closed.

  1. Install the SmartCRM Android app. Settings → Get app → scan the QR or tap the link to download the APK. Install it (Install from unknown sources — first time only).
  2. Log in. Same email + password as the web. The app silently registers an FCM token in the background.
  3. Allow notifications. First launch: Android shows a permission prompt. Tap Allow.
  4. Test it. On the web, ask a manager to assign you a new lead — within 1–2 seconds your phone should buzz with a banner.
  5. What triggers a push:
    • New lead assigned to you
    • Follow-up reminder is due
    • TAT breach
    • WhatsApp inbound on a thread you own
    • Tap-to-call request from desktop ("Call from phone")
💡
Web push (browser desktop notifications) also works on Chrome/Edge. The first time you log in on the web, the browser asks for notification permission — say Allow.

29📲 Mobile app install

Native Android wrapper — full CRM, with caller-ID, in-call recording sync, push notifications, and "tap-to-call from phone".

  1. Settings → Get app → tap "Download APK" (or scan the QR code from your phone).
  2. Allow "Install from unknown sources" for your browser, just for this install.
  3. Open the APK and tap Install.
  4. Open the app, log in.
  5. Grant the permissions the app asks for.
    Phone & CallsFor caller-ID overlay + auto-create-lead-on-incoming-call.
    NotificationsFor push.
    Storage / FilesFor attachment view + recording sync.
    LocationRequired — attendance check-in is blocked without GPS.
    MicrophoneOptional. For calls placed from the app.

iOS is on the roadmap. For now, iPhone users get a great PWA experience — just open the workspace URL in Safari and tap Share → Add to Home Screen.

30📞 Call recordings sync

Phone recordings show up against the matching lead automatically.

  1. Turn on call recording on your phone. Each phone OEM does it slightly differently — Samsung's auto-record, Pixel's per-call toggle, etc.
  2. Open the SmartCRM Android app at least once a day. The app syncs recordings in the background — when you open it, fresh recordings get uploaded.
  3. What gets matched:
    • Recording filenames with phone numbers — matched to lead by phone (with country-code-tolerant fuzzy match).
    • Samsung-style YYMMDD_HHMMSS_<contact-name>.m4a — matches the contact name to a lead.
    • Recordings without a number in the filename — matched by call-event timestamp ± 90 seconds against your dialled / received log.
  4. "1 skipped not in CRM" message. Recordings whose phone has never appeared as a lead get skipped (intentional — we don't want random recordings junking up the leads). To capture these, enable Auto-create lead from unmatched calls in Settings → Phone.

31🎨 Theme & branding

Make SmartCRM look like yours.

  1. Settings → Company. Upload logo (PNG with transparent background works best, max 1 MB). Set the company name.
  2. Pick brand colour. A single colour drives the active state, links, buttons, and the Android app icon background. Use your hex value or pick from the swatch.
  3. Theme mode. Light / Dark / Auto (follows the user's OS).
  4. Custom email signature. Settings → SMTP → Default signature. Used in transactional emails and quote emails.

32🔐 Permissions

Control who can do what at the action level.

  1. Settings → Permissions.
  2. Per-role permission matrix. Tick or untick individual capabilities for each role:
    • Edit lead, Delete lead, Reassign lead, Bulk actions
    • View other agents' leads
    • Send WhatsApp, Send templates, Send broadcasts
    • Edit settings, Manage users, See billing
    • Access reports, Export data
  3. Chat permissions (per-role). Settings → Chat permissions. Decide whether agents can see each other's WhatsApp threads, or only their own.
  4. Module visibility (per-role). Settings → Menu visibility. Hide entire features (eg. Reports, Quotations) from a role to declutter their UI.

99🛠️ Troubleshooting

Common issues and where to look.

Webhook returns 401API key wrong. Settings → Website API → click Regenerate and update on the sender side. Inbound table at the bottom of that page logs every rejected hit with a redacted prefix of the key it received.
